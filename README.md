# پیش پردازش متن - پروژه استاد اکبرپور

## اجرا

```
pip install nltk
python3 Kianoosh_Etminan.py
```

متن را در کادر بنویسید و «پردازش» را بزنید.
«متن ۱» و «متن ۲» و «متن ۳» فقط جمله نمونه را در کادر می گذارند.
«ارزیابی هر سه» هر سه جمله را با Precision و Recall نشان می دهد.

## منطق

متن وارد `preprocess` می شود و این چهار کار به ترتیب روی همان لیست انجام می شود. ترتیب کلمه ها حفظ می شود و تکرار پاک نمی شود.

1. توکن  
`RegexpTokenizer` از NLTK فقط سه جور الگو را برمی دارد: مخفف مثل `U.S.A.`، کلمه خط دار مثل `state-of-the-art`، و کلمه معمولی. اگر آخرش `'s` باشد آن دو حرف بریده می شود. چیزی که با این الگو جور نشود، مثل `. , ! ?`، اصلا وارد لیست نمی شود.

2. یکسان سازی  
برای هر توکن، اگر نقطه داشته باشد و بعد از حذف نقطه فقط حرف بماند، نقطه ها پاک می شوند. بعد `lower` می شود. برای همین `U.S.A.` و `USA` هر دو `usa` می شوند.

3. کلمات ایست  
لیست انگلیسی NLTK یک بار خوانده می شود. هر کلمه ای که داخل این لیست باشد از لیست حذف می شود. این کار قبل از ریشه یابی است تا شکل کلمه عوض نشده باشد.

4. ریشه  
اگر کلمه فقط حرف باشد `PorterStemmer.stem` صدا زده می شود. کلمه خط دار دست نمی خورد چون حرف خالص نیست. Porter پسوند را برمی دارد، مثلا authorization و authorized و authorizes می شوند `author` و `regularly` می شود `regularli`.

اگر متن دقیقا یکی از سه جمله نمونه باشد، خروجی با لیست طلایی همان جمله مقایسه می شود. هر دو طرف `set` می شوند تا تکرار حساب نشود.

Precision = تعداد اشتراک / تعداد خروجی برنامه  
Recall = تعداد اشتراک / تعداد خروجی طلایی  

اگر خروجی برنامه خالی باشد Precision صفر است. اگر طلایی خالی باشد Recall صفر است.  
کلمه ای که فقط در برنامه باشد «اضافه» است. کلمه ای که فقط در طلایی باشد «جا افتاده» است.
